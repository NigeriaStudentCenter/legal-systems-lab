Production verification pipeline

  1. Import published source records with documented rights to use them.
  2. Normalise names, administrative geography, coordinates and duplicates.
  3. Keep source details and observation dates attached to each record.
  4. Validate address and contact data through a documented, authorised public-source or station-confirmation process.
  5. Publish only verified status labels reflecting actual evidence.
  6. Run corrections and removal requests; reverify stale records.

Planned production statuses: imported/unverified → independently corroborated → locally confirmed. A directory listing is never a claim of police partnership.
