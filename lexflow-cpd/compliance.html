Authenticated platform: deployment requirements

Participant authentication

Entra External ID or a comparable configured identity provider, MFA for administrators, verified learner identifiers. Do not use this public site for collecting registration data.

Attendance evidence

Server-side timestamps, approved session IDs, instructor attestations and participation verification; never equate progress clicks with attendance.

Recordkeeping

Private Azure database with RBAC, audit logging, encryption, minimisation, backup and retention controls.

Accreditation register

Documented approval status and written award of any credit points, approved course version, provider identifier and expiry where relevant.

Reporting exports

Authenticated administrator exports participant enrolment and completion lists only for actual approved events; required format must be agreed with NBA-ICLE.

AI tutor gateway

Azure-hosted model behind authenticated server-side API, content filters, minimal retention and prohibition on real client files.
