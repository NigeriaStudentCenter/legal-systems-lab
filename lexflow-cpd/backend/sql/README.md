# CPD PostgreSQL migrations

Follows the sibling `lexflow-ng/backend/sql/` convention: PostgreSQL **15+**, numbered SQL migration files, applied manually or by an approved CI migration job **outside the API runtime**.

## Migration order

1. `001_initial.sql` — creates the CPD domain tables and indexes. Intended for a new empty CPD schema/database.

Operator steps:
1. Confirm selected environment, database, backup and change approval.
2. Connect with a dedicated **migration operator** identity permitted to execute DDL.
3. Apply the numbered migration once in order, recording the commit SHA and execution result in a separately maintained migration/change log.
4. Provision and grant the runtime login separately. The application does **not** create or alter any database object.

## Least-privilege runtime login

A privileged operator grants `CONNECT` on the selected database and `USAGE` on the schema, and **SELECT, INSERT, UPDATE** on only these tables:

`cpd_users`, `cpd_course_sessions`, `cpd_session_faculty`, `cpd_enrolments`, `cpd_attendance_events`, `cpd_course_approvals`, `cpd_certificates`, `cpd_audit_events`.

Do not grant DELETE, TRUNCATE, CREATE, ALTER, DROP, ownership or schema DDL permissions. PostgreSQL does not have a general ALTER privilege grant; ensure the runtime role is not owner or member of an owner role. Enforce default privileges accordingly. No sequence privileges are needed in migration 001 because IDs are generated by the app.

Example **operator-only** grant statements (replace role and database names after review):

```sql
GRANT CONNECT ON DATABASE lexflow_cpd TO lexflow_cpd_runtime;
GRANT USAGE ON SCHEMA public TO lexflow_cpd_runtime;
GRANT SELECT, INSERT, UPDATE ON TABLE
  cpd_users, cpd_course_sessions, cpd_session_faculty, cpd_enrolments,
  cpd_attendance_events, cpd_course_approvals, cpd_certificates, cpd_audit_events
TO lexflow_cpd_runtime;
```

Keep the operator and runtime identities distinct. Granting rights is not an application startup step. Prefer schema ownership by a non-login owner role and no broad grants on the public schema. The runtime should have a restricted search_path and no ability to create temporary tables if your policy forbids any DDL.

## Compliance

NBA-ICLE course approval and reporting must be separately confirmed. Records from this database do not themselves constitute accredited CPD evidence. No direct regulator connector is implemented.
