How the Legal AI Readiness Assessment is evaluated

A transparent 12-question diagnostic is scored against a fixed answer key. The result instantly reveals the recommended legal AI learning pathway. Where participants explicitly opt in, the authenticated Azure API recalculates the score and stores minimal educational statistics.

This is a demonstration, not a live Secretariat dashboard. All numerical examples below are invented. There is no regulator integration, regulator account, real learner reporting, verified CPD attendance or NBA-ICLE course accreditation. Access to real monitoring records requires BSOE and NBA-ICLE to agree roles, privacy safeguards and reporting arrangements.

Assessment and monitoring method

  1. Complete the assessment: 12 fictional professional decisions covering AI foundations, source verification, drafting, privacy and governance.
  2. Receive feedback instantly: each answer is marked against a fixed, published curriculum answer key. The result and suggested learning pathway appear immediately, even without an account.
  3. Course becomes available: users receive a clear link to the five-module 20-lesson Responsible AI for Nigerian Legal Practice programme. Free introductory study materials remain accessible.
  4. Optional secure submission: an authorised learner can choose to sign in through Microsoft Entra and submit answers to Azure for server-side regrading. The API stores score, domain summaries and learner identity internally, but not raw answer choices.
  5. Internal aggregate monitoring: only BSOE administrator accounts can access statistics through the protected API; aggregate summaries omit names and question-by-question answer choices.
  6. Regulator reporting: a future NBA-ICLE report or read-only role can be implemented only after explicit approval, privacy review, minimum-access definition and production deployment. It is not currently connected.

Operational status and safeguards

The assessment HTML and scoring policy are version-controlled. Azure reporting requires a privileged database migration (004_readiness_diagnostic.sql), reviewed runtime grants, successful API tests and a new immutable container deployment. The current deployed Azure revision must not be assumed to contain this new feature.

To demonstrate the monitoring workflow to NBA-ICLE, BSOE can show this page and arrange a guided session using fictional accounts. Real identifiable practitioner data must not be entered into the current shared development platform.
